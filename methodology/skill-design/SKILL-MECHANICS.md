# 技能机制

## 调用方式

两种，按「谁需要找到它」选：

- **模型自动触发**：保留 description，模型能自己找到，别的技能也能调用。代价是模型可见的 description 每轮都在上下文里。
- **用户手动触发**：设置 `disable-model-invocation: true`，description 只给人看，只有人输入名字才能调用，别的技能调不到。零上下文成本，但用户要记得它存在。

只给人用的，手动；需要模型自己找到、或别的技能要调的，自动。

## 按调用方式拆分

- 一个技能只有在需要独立触发词、或别的技能要调用它时，才拆成新的自动技能。
- 拆出去要付一条常驻 description；独立可达性要值这个价。
- 手动技能之间不能互相调用；两个手动技能都要用的材料，放到技能系统之外，双方用指针指向它。

## 路由技能

- 手动技能多到记不住时，用一个手动路由技能列出它们和各自的使用场景。
- 路由只能提示，不能代替人触发；手动技能没有模型可见的 description，别的技能调不到。
