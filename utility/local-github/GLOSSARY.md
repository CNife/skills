# 参考库（local-github）

`~/github` 下保存第三方仓库本地副本的上下文，目的是读 GitHub 代码与全库 grep。本表只定义这个上下文的用词。

## Language

**参考库**:
本地保存的一组 GitHub 仓库副本，只用于读代码，不用于修改。
_Avoid_: 仓库目录、镜像库

**副本**:
参考库中某个仓库的一份本地 git 克隆。
_Avoid_: 缓存、clone、repo

**规范名**:
副本的目录名，形如 `属主@仓库名`，大小写与 GitHub 一致。
_Avoid_: 目录名、别名

**浅副本**:
历史被截断到分支最新提交的副本；工作树完整，历史可按需补全。
_Avoid_: 精简副本、partial clone

**补史**:
把浅副本恢复成完整历史（当前分支与全部 tag），不改动工作树内容。
_Avoid_: 拉历史、解浅

**抓取**:
从远端取得新提交与引用，不改动工作树。
_Avoid_: 更新

**快进**:
工作树与当前分支前移到与上游一致，不产生合并提交；做不到时保持原位。
_Avoid_: 合并、pull

**刷新**:
对单个副本先抓取、再在不冲突时快进。
_Avoid_: 更新、拉取

**同步**:
对参考库内全部副本逐个执行刷新。
_Avoid_: 更新全部、pull all

**脏**:
工作区存在未提交的已跟踪文件改动。未跟踪文件不算脏。
_Avoid_: 不干净、有修改
