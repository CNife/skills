# Local GitHub

`~/github` 是**参考库**：第三方仓库各一份长期本地副本，目录名是**规范名** `属主@仓库名`，大小写与 GitHub 一致。

读 GitHub 上的代码走本地副本——能 grep、能整目录读、离线可用。

## 拿路径

```bash
~/.agents/skills/local-github/scripts/manage-local-github.py ensure 属主/仓库名
```

stdout 只有本地绝对路径，直接拿去读；副本缺失时它自己克隆。

**完成标准**：拿到一个存在的目录，之后的读取都在这个目录里做。

## 命令

| 命令 | 作用 |
| --- | --- |
| `ensure <仓库>` | 给出本地路径：缺则克隆，有则直接给，不联网 |
| `ensure --fresh <仓库>` | 先抓取并快进当前分支，再给路径 |
| `path <仓库>` | 只查本地，没有就非零退出 |
| `clone <仓库>` | 显式克隆；接受 `属主/仓库名`、`属主@仓库名` 或 GitHub 地址 |
| `sync` | 全库抓取，干净且有上游的做快进（默认子命令） |
| `list` | 按上次更新时间列出各仓库，标注命名与 origin 问题 |
| `rename` | 把裸名目录规范成 `属主@仓库名` |

`<仓库>` 一律是 `属主/仓库名`，大小写随意。

## 时机

- **新鲜度不作保证**：副本可能滞后任意久，需要上游最新内容时自己刷新——`ensure --fresh` 先抓取并快进再给路径，`gh api` 可直接看远端。
- **禁止修改 `~/github` 下的任何内容**：库里是参考资料，要改代码到库外另建工作副本；库内一旦有未提交改动，`sync` 会跳过它。
- **根目录**：`LOCAL_GITHUB_ROOT` 环境变量，默认 `~/github`。
