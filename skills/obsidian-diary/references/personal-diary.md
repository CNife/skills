# 个人日记变体规则

## Vault 路径

- 根目录：`/mnt/c/Obsidian/个人`
- 日记目录：`个人日记/YYYY/MM/`
- 文件命名：`YYYY年M月D日星期X.md`（如 `2026年4月17日星期五.md`）
- 模板文件：`个人日记/日记模板.md`

## 模板内容

新日记文件从模板复制，模板仅包含一个 `# 待办事项` 标题和 tasks 查询块。

## 格式规则

### 标题结构

- `# 主题标题` → 按主题分组（如 `# Textual 框架学习`、`# WSL2 浏览器配置`）
- 每个主题 1-2 行，同一件事合并为一行

### 内容类型

- **技术类**：关键决策和结论，不需要实现细节
- **学习类**：学到了什么、下一步
- **生活类**：操作、观点、趣事

### 语气

比工作日志更轻松，可以保留个人观点和感受。这是刻意保持的特色，不要写成干巴巴的工作报告。

## 区分工作与个人

- 公司项目开发、部署、运维、正式会议 → 使用 work 变体
- 个人技术探索、学习笔记、投资复盘、生活记录 → 本变体
- 混合内容 → 只记录个人部分，末尾提示用户是否也需要工作日志

## 示例结构

文件开头固定为 `# 待办事项` + tasks 查询块，之后按主题分组：

````text
# 待办事项
```tasks
not done
```
````
